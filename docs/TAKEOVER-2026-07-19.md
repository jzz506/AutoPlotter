## 1. 项目定位与架构

- **定位**：纯本地、纯前端的数据分析与绘图应用。所有数据仅在本机浏览器 / WebView 内存中处理，无后端、无数据库、无网络上传。
- **技术栈**：React 19 + TypeScript（strict）+ Vite + Papa Parse + SheetJS (xlsx) + Plotly.js + Vitest + Playwright + oxlint；桌面壳为 Tauri 2（Rust 侧仅 dialog + fs 插件，无业务逻辑）。
- **核心架构**：
  - 全部状态集中于 `src/state/AppContext.tsx`（useReducer）。
  - 原始数据（`state.original`）永不修改；处理步骤记录为 `Operation[]`，由纯函数派生工作数据；恢复原始数据 = 清空操作数组。
  - `src/lib/` 主要承载不依赖 DOM 的纯函数模块，核心逻辑已有 Vitest 单测覆盖。
  - 图表配置为可序列化的 `ChartConfig`；`buildChart` 为纯函数，类型兼容性校验集中于此，以中文返回错误。
  - 新增处理操作需三处保持一致：`types.ts` 的 `Operation` 联合类型、`transform.ts` 实现、`python.ts` 的 pandas 代码生成。
